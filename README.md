# AfriBoost V3.0 Final

Prototype réel Next.js de la plateforme AfriBoost, avec une identité visuelle construite à partir de zéro.

## Lancer

```bash
npm install
npm run dev
```

Puis : http://localhost:3000

## À connecter avant production

- Supabase/PostgreSQL + authentification
- Données réelles emplois/formations/marketplace
- AfriBoost AI via API serveur
- Paiements et webhooks
- Stockage des fichiers
- Emails et notifications
- RLS, rate limiting, logs et monitoring
- Domaine et déploiement

Les données visibles dans cette version sont des données de démonstration. Ne pas présenter les chiffres ou offres comme réels avant connexion à des sources vérifiées.
